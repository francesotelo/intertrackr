# InternTrackr Web Platform 🚀

InternTrackr is a full-stack web application designed to help university students track their internship application pipelines, manage outreach, and organize their career journeys. 

## 🛠️ Tech Stack
* **Frontend:** React.js
* **Backend:** Node.js & Express.js
* **Database:** MongoDB
* **Deployment:** Vercel 

## 📂 Project Structure
This repository is a monorepo separated into two primary directories:
* `/client` - Contains the React user interface and frontend logic.
* `/server` - Contains the Node.js/Express backend API and database connections.
